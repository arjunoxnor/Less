# Audit: the editor panels, menus and modals

The chrome and UI primitives were audited. The PANELS were not: they are where
a writer spends real time, and they read the document continuously while it
changes underneath them.

Scope, and nothing else: `components/SceneNavigatorPanel.tsx`,
`CastListPanel.tsx`, `ReportsPanel.tsx`, `NotesPanel.tsx`,
`BreakdownPanel.tsx`, `FindReplacePanel.tsx`, `HistoryPanel.tsx`,
`CommandPalette.tsx`, `AutocompleteMenu.tsx`, `SpellMenu.tsx`,
`TitlePageModal.tsx`, `AuthModal.tsx`, `StorageBanner.tsx`,
`PageBackdrop.tsx`, `PlainToolbar.tsx`, `DuetShareModal.tsx`,
`SessionExpiredBanner.tsx`. Do NOT touch `lib/`, `app/globals.css`,
`components/ScreenplayBody.tsx`, `components/PlainBody.tsx`,
`components/ProjectsHome.tsx`, `components/chrome/`, `components/ui/`, or
`duet/`: parallel audits own those and your edits there will be discarded.

## What to look for

1. Each panel against an empty document, a one-line document, and a
   200-page one. Nothing may hang, and a panel must not recompute the whole
   document on every keystroke.
2. The document changing while a panel is open: a scene deleted while the
   navigator shows it, a character renamed while the cast list is open, a note
   deleted while its row is focused, a history restore while the panel lists
   versions. Clicking a stale row must not jump to a wrong position or throw.
3. Find and replace: an empty query, a query of only spaces, a query longer
   than the document, replace-all with an empty replacement, replacing text
   that contains the query, matches inside collapsed or hidden content, and
   undo after a replace-all.
4. The command palette: filtering with no matches, keyboard navigation to the
   ends of the list, running a command whose target vanished, and Escape while
   a submenu is open.
5. Every panel and modal: keyboard reachable, focus trapped where it should be
   and restored on close, Escape ordering correct when several are stacked,
   and no aria state that lies.
6. Every list: correct behaviour when it is empty, when it has one item, and
   when it has thousands.

## Definition of done

Every real bug fixed with a regression test. `npx tsc --noEmit && npm test`
pass. Report at `superaudit/2026-08-03-panels-report.md` with a one-line
reproduction each, ranked by likelihood.
