# Audit: data loss, storage limits and recovery

Losing a writer's work is the one unacceptable failure in this project. This
audit attacks the storage and sync layer specifically looking for ways a
character can disappear.

Scope: `lib/storage/**` and `lib/cloud/**` only. Do not touch `lib/editor/`,
`lib/export/`, `components/`, `duet/` or `lib/collab/`: other audits own those.

## Scenarios to drive, not merely reason about

1. localStorage full: a save that throws QuotaExceededError mid-write, an
   eviction that runs while an editor is open, a quota failure on the index
   itself rather than a body, and a browser where localStorage throws on every
   access (private mode).
2. Corrupted storage: an index that is not JSON, an index that is JSON but not
   an array, a project entry missing required fields, a body key present with
   no index entry and the reverse, ids that collide, and values truncated
   mid-write by a crash.
3. Cross-tab: the same project open in two tabs, both typing; one tab deleting
   what the other is editing; a tab restoring history while another saves; and
   the broadcast channel being unavailable.
4. Cloud sync: a 401 mid-flight, a 500, a timeout, a response that arrives
   after the editor unmounted, the same project reconciling twice
   concurrently, a clock skewed by hours in either direction, and a cloud row
   that is newer for content but older for the title.
5. The version history ring: it must never be the only copy of anything, must
   not grow without bound, and restoring must be undoable.
6. Migration: the legacy single-document migration must be idempotent and must
   never run twice or lose the original.

## What to fix

Anything that can lose or duplicate content, resurrect a deleted project, or
leave the index and the bodies disagreeing. Prefer the option that keeps a
copy over the option that is tidy.

## Definition of done

Every real bug fixed with a regression test. `npx tsc --noEmit && npm test`
pass. Report at `superaudit/2026-08-03-dataloss-report.md`, ranked by how much
work each bug could destroy.
